# Демо-данные

`data/*.csv` — детерминированные наборы для рецептов из `recipes/`.
Все файлы в UTF-8, с заголовком, не более 200 строк данных и без внешних
зависимостей: их можно сгенерировать повторно из тех же формул.

| Файл | Строк | Колонки | Что демонстрирует |
|---|---:|---|---|
| `quality.csv` | 24 | `id,email,amount,status` | Проверки качества: пустой `email`, повторяющиеся `id`, отрицательный `amount`. |
| `cohort.csv` | 160 | `user_id,signup_date,activity_date` | 40 пользователей, когорты по месяцу регистрации (январь-март 2026) и активность до трёх месяцев после неё. Даты ISO. |
| `ab_test.csv` | 120 | `user_id,variant,converted` | Две группы `control`/`treatment`, бинарная конверсия: 24/60 и 36/60. |
| `timeseries.csv` | 45 | `date,value` | 45 ежедневных точек с трендом, недельной сезонностью и детерминированным шумом. `date` — timestamp вида `2026-01-01 00:00:00`. |
| `segmentation.csv` | 120 | `customer_id,age,income,spend,frequency` | Три устойчивых сегмента клиентов с разными уровнями дохода и расходов. |
| `regression.csv` | 100 | `age,income,spend` | `spend` линейно зависит от `age` и `income` плюс небольшой детерминированный шум. |
| `funnel.csv` | 148 | `user_id,step,ts` | Шаги `view` (60), `cart` (42), `checkout` (28), `purchase` (18); `ts` — локальный timestamp без часового пояса. |
| `sales.csv` | 100 | `region,amount,date` | Пять регионов по 20 дней марта 2026; суммы растут по дням и различаются по регионам. |

Пустая ячейка в `quality.csv` читается как NULL. Даты в `cohort.csv`,
`sales.csv` и `timeseries.csv` отсортированы по возрастанию внутри каждой
группы; порядок строк детерминирован.

Эти файлы используются тестом `python3 tests/recipe_library_e2e.py`: для
каждого CSV вызывается `dap_ingest`, затем соответствующий рецепт получает
Parquet-кэш в качестве `dataset`.
