# P6 «Аналитик» — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpower-subagent-driven-development
> (recommended) or superpower-executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** закрыть семь дефицитов DAP из запроса пользователя и заметки практического
прогона: глубина статистики, универсальность данных, out-of-core, эффективность агента,
визуализация, многотабличные отчёты, allowlist путей.

**Architecture:** движок остаётся SQL-планами над DuckDB; статистика, которой нужны
матрицы, читает ограниченный срез в Java и возвращает `LazyPlan` с литералами. MCP-адаптер
остаётся stdlib-Python и ходит только в `/v1`. Новые сквозные компоненты: `PathGuard`,
`DatasetCatalog`, `ExploreService`, `ReportWriter`, `ChartRenderer`, `ProgressListener`.

**Tech Stack:** Java 21, DuckDB 1.5.6, Arrow 19, Javalin 6.7, JUnit 5.11, Python 3 stdlib.

**Spec:** `docs/superpowers/specs/2026-11-15-p6-analyst-design.md`

## Global Constraints

- Никаких новых runtime-зависимостей: только JDK, DuckDB, Arrow, Jackson, Javalin,
  SLF4J/logback. PDF/PPTX/HTML — свои writer-ы на JDK (`java.util.zip`, `ImageIO`, Java2D).
- Существующие id узлов, инструменты и аргументы не удалять; новые поля опциональны.
- Каждый новый узел: spec JSON + строка в `specs/index.txt` + executor + регистрация в
  `NativeService.defaultExecutors` + ≥3 JUnit-теста + раздел в `docs/NODES.md`.
- Правка `/v1`: `api/openapi.yaml` + `docs/API.md`.
- Коммиты conventional, английский: `feat(nodes): …`, `feat(mcp): …`, `test: …`.
- Ветки: каждая рабочая группа — свой worktree `.worktrees/p6-*`; в общем дереве и в
  `phase3-native` не работать.
- Maven в worktree: `DAP_JDK="$HOME/Projects/tools/jdk-21.0.13+9/Contents/Home"`,
  `DAP_TOOLS="/Users/vitalypesnev/Projects/dap/engine-native/.tools"`.
- Python: `~/miniforge3/bin/python3`.
- Перед коммитом задачи: точечные тесты; в конце workstream — полный `./mvnw -q test`
  (или `python3 -m unittest ...`). Полный `make check` — интегратор.
- Не менять `VERSION` и версии в OpenAPI/адаптере: релизный bump 1.2.0 делает интегратор.

## Review Focus

- **Пути и секреты:** `read_parquet('/Users/.../.ssh/...')`, `where`-инъекция,
  `COPY ... TO` — должны давать 400 `path_not_allowed`, а не читать файл.
- **Пустые/одноэлементные данные:** корреляция при n<3, регрессия при n≤p, кластеры при
  k>n, ACF при коротком ряду, boxplot при одном значении — понятная ошибка или NULL, не
  падение.
- **Обратная совместимость:** старые вызовы `dap_get_table`/`dap_sql`/`dap_report`
  без новых аргументов дают прежнюю форму ответа (кроме задокументированных новых колонок).
- **Детерминизм:** SVG/PNG/PDF/PPTX при одном входе байт-в-байт одинаковы; гипотезы
  `dap_explore` в стабильном порядке.
- **Память:** `parquet_reader` не грузит таблицу в heap; `file_reader` не читает файл
  целиком в Java; ingest большого CSV не строит Arrow-таблицу.
