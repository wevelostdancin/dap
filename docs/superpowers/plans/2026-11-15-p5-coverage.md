# DAP MCP Service — Phase 2: Coverage Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpower-subagent-driven-development (recommended) or superpower-executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reach 67 of 69 analytics tasks offline by adding 8 nodes, 3 extensions and 7 SQL recipes, each proven by a coverage scenario.

**Architecture:** Nodes are spec JSON + executor returning `LazyPlan` (SQL + declared columns), exactly like the existing 44. SQL-only capabilities stay recipes over `dap.sql_query` (YAGNI: no node for one expression). Coverage is a task suite (`tests/coverage/`) that runs every scenario through `/v1` and reports PASS/69.

**Tech Stack:** Java 21, DuckDB 1.5.6 (sqlite/postgres/httpfs extensions), Arrow 19, JUnit 5.11.4, Python 3 stdlib harness.

**Spec:** `docs/superpowers/specs/2026-11-15-dap-mcp-service-design.md` (§6, §8)

## Global Constraints

- No new Maven dependencies; jar stays under 50 MiB (`scripts/check_repo.py` enforces it).
- Every node: spec JSON + executor + >=3 JUnit tests + golden + row in `docs/NODES.md` + coverage scenario.
- `/v1` changes update `api/openapi.yaml` and `docs/API.md`; node docs go to `docs/NODES.md`.
- Extensions install into `DAP_DUCKDB_EXTENSION_DIR`; goldens and tests must run offline (SQLite fixture, no network).
- Commits conventional, English; `make check` green after every task.
- Worktrees: `.worktrees/p5-sql-io` (branch `p5/sql-io`), `.worktrees/p5-stats` (`p5/stats`), `.worktrees/p5-output` (`p5/output`). One writer per worktree.

## Review Focus

1. `sql_query` with DDL, multiple statements or `;` inside a string literal - rejected or correctly parsed, never executed.
2. `sql_query` over node outputs with duplicate result aliases - columns renamed deterministically (`a`, `a_1`) and declared in the plan.
3. `db_reader` without an installed extension - actionable error with the `make extensions` hint; credentials never appear in `workflow.json` or logs.
4. `group_by` median/percentile over Decimal and NULL - correct Arrow type and NULL handling.
5. `chart` SVG is byte-deterministic (golden), PNG is not compared byte-wise.
